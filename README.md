# Tic Tac Toe

A small two-player tic-tac-toe game that runs in the browser. HTML, CSS, and JavaScript. No install and no build step.

## Global Hack Week

This project is the entry for **CHALLENGE 1: Build a Mini App with Cursor**, a beginner challenge at [Global Hack Week: Hacktoberfest](https://www.mlh.com/events/global-hack-week-open-source-90/challenges).

The challenge asks for a small working app built from scratch with Cursor. This one is a pass-and-play board: two players share a device, the game detects wins and draws, and it keeps score across rounds.

- Challenge: [CHALLENGE 1: Build a Mini App with Cursor](https://www.mlh.com/events/global-hack-week-open-source-90/challenges/01a11d23-3841-86cf-2fa3-5e70600e8f08)
- Submit on the [Global Hack Week challenges dashboard](https://ghw.mlh.io/challenges)

Cursor scaffolded the page, the board logic, and the layout from an empty folder, then fixed the cells so they stay keyboard-accessible and the board fits on a smaller screen.

## How to play

Open `index.html` in a browser.

- X goes first. Click a cell to place a mark, then hand the device to the other player.
- Three in a row turns green and ends the round. A full board with no winner is a draw.
- **New game** clears the board and keeps the score.
- **Reset scores** clears the board and the score.
